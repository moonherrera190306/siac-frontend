# 🎓 SIAC - Sistema Integral Académico

Sistema web para la gestión académica de instituciones educativas, incluyendo control de alumnos, docentes, pagos, calificaciones y reportes.

---

## 🚀 Tecnologías

### Frontend
- Next.js 16
- React
- Tailwind CSS

### Backend
- Node.js
- Express
- Prisma ORM
- PostgreSQL

### Deploy
- Frontend: Vercel
- Backend: Railway

---

## 🌐 Producción

Frontend:
👉 https://TU-FRONTEND.vercel.app

Backend:
👉 https://siac-backend-production.up.railway.app

---

## 🔐 Funcionalidades

- Login con roles:
  - ADMIN
  - DIRECTOR
  - MAESTRO
  - ALUMNO
  - SECRETARIA
  - CAJA

- Gestión de:
  - Alumnos
  - Docentes
  - Materias
  - Grupos
  - Pagos
  - Calificaciones
  - Reportes
